A dip-and-recover trading bot for Coinbase Wrapped BTC (cbBTC) against USDC: it buys when the price dips at least 60 bps below its 60-bar EMA and sells the recovery, with take-profit, stop-loss and trailing-stop exits. On the dev window it made +6.83 USDC over 4 trades with a 0.71% maximum drawdown.

## Run it

```sh
node main.ts
```
